The stack
four execution tiers — two run with your full user authority
FULL OS AUTHORITY Launcher /Applications/Discord.app → app.asar · 39 source files
Splash screen, updater, connectivity tests. This is all you actually installed. It downloads everything else.
↓   fetches + loads the real program   ~/Library/Application Support/discord/0.0.380/
FULL OS AUTHORITY Main process core.asar → app/index.js · 24 browser modules
Registers 136 privileged IPC endpoints, builds the window, installs the permission and navigation fences. Owns the filesystem, the keychain, the screen.
↓   webPreferences.preload   — attached by filename, not by import
NODE ENABLED · sandbox:false Preload mainScreenPreload.js · 26 capability modules
The tier that matters. Holds full Node in the same process as remote content — reads your clipboard and filesystem directly, without ever crossing IPC.
contextBridge.exposeInMainWorld('DiscordNative', …)  — the only door
ISOLATED · NO NODE Renderer https://discord.com/app — loaded over the network, every launch
Chat, voice UI, servers, settings. None of it ships in the app. The desktop client is a browser window pointed at the website.
↓   loaded by name at runtime, from a user-writable folder
COMPILED · NOT ANALYSED Native modules discord_voice 81 MB · discord_krisp 52 MB · dispatch · notifications
Where voice capture and the Rust updater live. The boundary of this report — it needs a decompiler, and that is said plainly rather than guessed at.
